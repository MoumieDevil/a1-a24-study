# A1–A24 数量关系学习站

中文招聘笔试课余学习教材，适合手机、平板和电脑。参考 EE6301 学习站的常驻目录、字号调整和折叠解析。

- 完整31个单元：A1–A24，其中A8分8类行程。
- 123题：31精讲、62练习、6诊断、24小测，全部附分步解答。
- 按章节/未作答/收藏筛题，随机练10题，支持多字段、分数、百分数和无序数字集合判分。
- 做错自动进入错题本，答对转到已订正，保留错因笔记和历史次数。
- 全文搜索、图解放大、字号调整、学习进度与12组考前速查。
- PDF和Markdown教材下载；首次联网访问后可缓存核心页面供离线学习。

学习记录保存在当前浏览器的localStorage，不会上传到GitHub。不同设备之间不自动同步；使用“学习记录与备份”导出JSON，在另一设备导入合并。清除浏览器数据前请先备份。该仓库和网站公开，只包含原创学习资料与网页代码。

## GitHub Pages

发布根目录，分支main，目录`/ (root)`，`.nojekyll`使静态文件直接提供。无需服务端和外部CDN。页面使用哈希路由，直接分享章节地址不会产生404。

## 本地运行

```text
python -m http.server 8765 --bind 127.0.0.1
```

打开`http://127.0.0.1:8765/`。需要通过HTTP服务打开，避免直接打开文件时浏览器限制模块和离线缓存。

`course-data.js`保存结构化教材。修改内容后需提高`sw.js`的缓存版本，再发布，避免旧资源残留。源教材PDF保留原版；网页版补清少量出发方向、计时起止和情景表述，具体记录见“教材下载”。

## 验证

已对全部题目的预期答案做内容核验。判分与记录引擎还覆盖分数、多字段、空答案、错题订正、备份恢复与重复合并。部署时另外检查手机、平板和桌面的实际阅读与练习。
